Сэдэв: 2.Цагаан сарын бууз 
:Зочдын тоо, хүнд ногдох бууз → хэрэгтэй гурил, мах, бэлтгэх цаг;
шинийн 1–5-ны өдөр бүрийн хүснэгт; 3 айлын буузны тоог ихээс бага
руу эрэмбэлэх.
Бууз хийхэд:
Жишээ:
1 бууз хийхэд:
         {хэрэгтэй гурил: 15гр,
          хэрэгтэй мах: 20гр,
          бэлдэх хугацаа: ~30сек,}
1 хүнд: 8 ширхэг бууз,
Өдөрт ирэх зочин: 10-100,
Өдрүүд: Шинийн 1: 100%,
        Шинийн 2: 80%,
        Шинийн 3: 60%,
        Шинийн 4: 40%,
        Шинийн 5: 20%,
